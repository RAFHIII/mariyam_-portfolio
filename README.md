# Mariyam's Portfolio (fram_e8m)

A modern, high-performance creative portfolio showcasing video editing, visual storytelling, and creative direction.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Styling**: Tailwind CSS
- **Animations & Effects**: Framer Motion, GSAP, OGL (WebGL / Dither Shader)
- **Icons & UI**: Lucide React, Radix UI

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for Production

```bash
npm run build
npm start
```
